# ModMenuBE 0.2.0-local3 本地測試

這是 Windows x64 原生本地整合候選版，不是已經合併到 AFAlimru 上游的版本。已包含 1.26.45.01、1.26.51.01、1.26.52.03、1.26.60.05 的既有精確映像檢查；未知 EXE 或未核實掛鉤會拒絕啟用。離線測試與 TestHost 顯示不代表四個版本的遊戲驗收。

## 安裝與回復

1. 完全退出遊戲。先備份自己的 ModMenu 插件資料夾與設定。
2. 暫停載入原 `ModMenuBedrock`（及其 LL 版本）與其他重複的 ModMenuBE，避免同時存在兩個選單。只改啟用狀態，不刪設定。
3. 解壓測試包，把 `mods/ModMenuBE` 放到指定測試實例根目錄。包內沒有設定檔，不覆蓋玩家設定。這個候選版使用獨立 `mods/ModMenuBE/config/config.json`；不會自動遷移舊 ModMenuBedrock 設定。
4. 第一輪先不載入 BedrockToolNative。它仍要求舊 Workspace，這次沒有移植。
5. MouseTweaks 僅接受已核實的 0.3.2-test1（158208 bytes，2F289102…）／0.3.3-test1-vanilla51（158720 bytes，77425954…）。未知版本會使原生橋接拒絕啟用；26.60 的 0.4.0-test1 尚待獨立適配，首測先停用。
6. 回復時退出遊戲、停用本測試版、恢復先前啟用狀態與備份即可。本輪沒有自動安裝或啟動遊戲。

## 人工檢查

- 本輪優先：開啟任一普通插件的 Configure，確認上列 Apply／Cancel 與說明、下列快捷鍵／狀態提示互不重疊。縮小視窗並調整 UI 縮放，檢查按鈕仍可點擊；長說明可以在右側截斷，但不得蓋到 Cancel。分別測一次 Cancel 不儲存、Apply 後重開保留。
- 先測先前報錯的 1.26.52.03：啟動時不應再出現「找不到序號 101」。不需刪除或替換實例中的 `d3d12.dll`，本包也沒有包含該檔。確認主選單有 Mods、F10 能開啟，再測暫停選單。若仍有錯誤，保留新截圖及 `mods/ModMenuBE/logs/latest.log`；尚未產生日誌本身也是診斷資訊。
- 原生主選單應有 Mods 入口；F10 預設可開啟。暫停選單同樣測一次。原版設定頁、背包及 HUD 中不能開啟。新增 Windows 按鍵支援仍受系統保留快捷鍵影響，例如 Win／Alt＋Tab 不保證能攔截系統動作。
- 清單只顯示已載入 DLL 和選單自身；僅放在資料夾、未載入的模組不作為運行中插件列出。已載入後才停用的模組仍可能保留到重啟。
- 先選一個已有 `modmenu.settings.json` 的普通插件。進設定修改後 Cancel，重開應還是舊值；再 Apply，重開應保留。實際功能是否熱載入由插件本身決定，請分別觀察。
- 測一個小數 Slider，確認刻度與數值一致。整數／文字輸入不合法時應顯示錯誤、停用 Apply；Reset 可恢復。未編輯的 JSON 欄位應保留。
- `binding` 欄捕捉 Ctrl＋Shift＋左 Alt＋K 或一組較簡單的組合，Apply 後驗證插件觸發；Esc 捕捉為 NONE，不能關閉設定頁。舊 `key` 欄只接受原有宣告鍵名。
- ModMenuBE 自己的設定中可捕捉新開啟鍵，Done 儲存。若清為 NONE，仍能使用原生 Mods／材質包入口。上游 C API 設定採即時 setter，沒有被動 sidecar 的 Apply／Cancel 交易語義。
- 開在設定頁，切至其他應用再返回：相同主／暫停場景應保留頁面、草稿及捲動。按住滑鼠或鍵盤返回時先不應觸發，全部放開後才恢復。若原場景已換掉，舊頁不得恢復。
- 自訂材質包入口使用 `button.modmenu.open`；原生主／暫停 JSON UI 生效。已有該入口不得重複插入預設按鈕。26.60 的自動插入只授權已核實的原版 payload，自訂包需自身提供入口。
- 最後加入對應已核實 MouseTweaks，重新啟動後檢查選單、拖曳搬運、滾輪、關閉返回及正常遊戲輸入。

第一次先選一個版本完成以上檢查，再逐一測其餘三個版本；不需要重做其他插件已驗收的整套功能。

## 日誌及範圍

日誌：`mods/ModMenuBE/logs/latest.log`。若沒有按鈕／F10，先看 `Local bridge inactive/refused`、版本及共用掛鉤原因，再對照實際 DLL 雜湊；不要刪安全檢查。界面支援上游繁中／英文，auto 跟隨已核實的遊戲語言；被動欄位可使用描述檔中的繁中／簡中／英文。上游尚無完整簡中詞表時以繁中呈現選單。

本版不包含舊 Workspace、BedrockTool UI、地圖控件或登入任務。既有上游 external-screen API 保留，點擊會交給插件自己的介面。
